# Linux User Management

## Project Overview
This project demonstrates basic Linux user management and user permission configuration using Linux commands on Red Hat Enterprise Linux (RHEL 8).

## Objectives
- Create Linux user accounts.
- Modify existing user accounts.
- Set and change user passwords.
- Manage user account information.
- Configure file and directory permissions.
- Understand basic Linux user administration.

## Technologies Used
- Operating System: Red Hat Enterprise Linux (RHEL 8)
- Virtualization: Oracle VirtualBox
- Interface: Linux Terminal

## Commands Used

| Command | Purpose |
|---|---|
| `useradd` | Create a new user |
| `passwd` | Set or change user password |
| `usermod` | Modify user account details |
| `userdel` | Delete a user account |
| `id` | Display user ID information |
| `whoami` | Display current username |
| `chmod` | Modify file permissions |
| `chown` | Change file ownership |

## Practical Implementation

1. Created new Linux user accounts.
2. Modified existing user account details.
3. Configured and changed user passwords.
4. Checked user account information.
5. Managed file and directory permissions.

## Key Learnings
- Linux user account creation.
- User account modification.
- Password management.
- File ownership and permissions.
- Basic Linux system administration.

## Project Outcome
Successfully performed basic Linux user administration and practiced managing user accounts and file permissions in RHEL 8.
